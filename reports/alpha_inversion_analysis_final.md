## 4. 근본 원인 분석

### 가능한 원인

#### 1. Gaussian 위치 최적화 불균형
- RGB loss (weight=1.0)가 alpha loss (weight=0.1)보다 10배 강함
- 모델이 RGB 재구성 위주로 최적화
- 배경(흰색)을 맞추기 위해 Gaussian이 퍼짐

#### 2. Input vs Novel View 학습 비대칭
- Input views: 모델이 직접 "본" 뷰 -> 과적합 가능성
- Novel view: 일반화된 예측 -> 더 정확한 형상 표현

#### 3. 초기화 및 학습 단계 문제
- Step 601은 초기 학습 단계
- Gaussian이 아직 물체 영역에 집중되지 않음
- 배경 영역에도 높은 opacity Gaussian 존재

### 근본 원인 추정

**가장 가능성 높은 원인**: RGB 손실이 지배적이어서 Gaussian이 배경 영역에도 배치되고,
이 Gaussian들의 opacity가 높아서 배경에서 높은 alpha가 렌더링됨.

Input views에서 이 현상이 더 심한 이유:
- 모델이 input views의 RGB를 정확히 재구성하려 최적화
- Novel view는 일반화된 형태로 렌더링되어 상대적으로 정상적인 alpha 분포
