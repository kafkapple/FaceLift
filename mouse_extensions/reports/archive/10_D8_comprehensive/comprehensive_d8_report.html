D8 Homography Transform

The key difference from D7 is using homography instead of affine:

\[ H = K_{target} \cdot K_{orig}^{-1} \]

This correctly handles:

  • Skew correction: Original skew values (-5.82 to +1.39 px) are removed
  • fx/fy unification: Both become exactly 548.9937744140625
  • PP centering: Principal point moves to (256, 256)

7. Mathematical Verification

7.1 Ray Direction Calculation

For pixel (u, v), the ray direction in camera coordinates:

\[ \mathbf{d}_c = \begin{bmatrix} (u - c_x) / f_x \\ (v - c_y) / f_y \\ 1 \end{bmatrix} \]

7.2 D8 Ray Error Verification

At image edge (u=0 or u=512):

\[ \theta_{error} = \arctan\left(\frac{\Delta c_x}{f_x}\right) \]

For D8 with cx=256, cy=256 (exact): ray error ~0 deg

For D4 with PP error ~37px: ray error = arctan(37/549) ≈ 3.9 deg
