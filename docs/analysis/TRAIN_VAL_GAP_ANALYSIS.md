## 1. 개요

### 1.1 Train-Val Gap의 의미

| Gap 유형 | 의미 | 해석 |
|----------|------|------|
| **음수 (Train < Val)** | 이례적 | 데이터 특성 또는 일반화 우수 |
| **작음 (<5)** | 정상 | 좋은 일반화 |
| **중간 (5-10)** | 주의 | 약간의 과적합 |
| **큼 (>10)** | 문제 | 심한 과적합 |

### 1.2 핵심 발견

```
D3_normalized: Train 24.07 < Val 27.09 (Gap = -3.0) ★ 이례적
D7_1_E0_paper: Train 24.58 > Val 20.93 (Gap = +3.6) ○ 정상
D7_1_E1_gt:    Train 28.21 > Val 17.89 (Gap = +10.3) ✗ 과적합
```

## 3. 패턴 분석

### 3.1 E0 vs E1/E2 비교 (동일 D7_1 데이터셋)

| 설정 | mask_mode | Val PSNR | Gap | 분석 |
|------|-----------|----------|-----|------|
| **E0_paper** | none | **20.93** | +3.7 | 최고 성능, 낮은 Gap |
| E0_mouse | none | 19.86 | +8.3 | 양호 |
| E1_gt | gt | 17.89 | +10.3 | 과적합 |
| E2_gt_alpha | gt + alpha | 16.96 | +7.8 | 과적합 |

**관찰**:
- **mask_mode=none (E0)이 가장 낮은 Gap + 높은 Val PSNR**
- GT mask 사용 시 Train은 높아지나 Val은 낮아짐 → 과적합 유도

### 3.2 View 수 영향 (D7_1 + E2)

| Views | Val PSNR | Gap | 분석 |
|-------|----------|-----|------|
| 4v (기본) | 16.96 | +7.8 | 기준 |
| 3v | 14.17 | +10.4 | Gap 증가, 정보 부족 |
| Fixed 4v | 17.08 | +7.5 | Random과 유사 |

**관찰**: 3v는 Gap 증가 → 정보 부족으로 과적합 심화

### 3.3 데이터셋별 비교 (E0_paper 동일 설정)

| 데이터셋 | Coverage | fx | PP | Val PSNR | Gap |
|----------|----------|-----|-----|----------|-----|
| **D3_normalized** | ~6% | 549 | 256 | **27.09** | **-3.0** |
| D7_1 | 50% | 549 | 256 | 20.93 | +3.7 |
| D8 | 50% | 549 | 256 | 20.21 | +6.6 |

**관찰**:
- D3의 높은 Coverage (~6%)가 일반화 향상
- **음수 Gap은 Coverage와 상관?**

## 4. D3_normalized 음수 Gap 분석

### 4.1 현상

```
Train PSNR: 24.07
Val PSNR:   27.09
Gap:        -3.02 (Val이 Train보다 높음!)
```

### 4.2 가능한 원인

| 가설 | 설명 | 가능성 |
|------|------|--------|
| **A. Data Split 특성** | Val 세트가 더 쉬운 샘플 포함 | ★★★ |
| **B. Coverage 효과** | ~6% Coverage가 일반화 극대화 | ★★☆ |
| **C. 비정방형 fx/fy** | 0.9937 비율이 기하학적 왜곡 감소 | ★☆☆ |
| **D. PP 고정 (256)** | PP 분산 없음 → 안정적 학습 | ★★☆ |

### 4.3 검증 방법

| 가설 | 검증 실험 |
|------|-----------|
| A | D3_normalized의 train/val 샘플 난이도 분석 |
| B | M3_persample (80%, PP=256) + E0 결과 확인 |
| C | D7_1에 fx/fy=0.99 적용한 실험 |
| D | M3_norm (PP 가변) vs M3_persample (PP=256) 비교 |

## 5. 가설 연결

### H1: Coverage → PSNR

| 근거 | 데이터 |
|------|--------|
| D3 (~6%) | Val PSNR 27.1, Gap -3.0 |
| D7_1 (50%) | Val PSNR 20.9, Gap +3.7 |
| **결론** | Coverage↑ → Val PSNR↑ + Gap↓ |

### H2: fx=549 필수 (검증됨)

| 근거 | 데이터 |
|------|--------|
| M3 (fx=739) | Val PSNR 10.6, Gap +13.4 |
| D7_1 (fx=549) | Val PSNR 20.9, Gap +3.7 |
| **결론** | fx 정규화 없으면 학습 실패 |

| 근거 | 데이터 |
|------|--------|

| E1 (gt) | Val 17.9, Gap +10.3 |
| E2 (gt+alpha) | Val 17.0, Gap +7.8 |
| **결론** | GT mask가 과적합 유도 |

## 6. 정성적 분석

### 6.1 예상되는 시각적 특성

| Gap 범위 | Train | Val | 예상 시각 결과 |
|----------|-------|-----|----------------|
| **음수** | 보통 | 우수 | 깔끔한 재구성, 노이즈 없음 |
| **작음** | 양호 | 양호 | 약간의 블러, 형태 정확 |
| **중간** | 우수 | 보통 | Train 과적합 징후, Val에서 ghosting |
| **큼** | 우수 | 불량 | 심한 ghosting, 형태 왜곡 |

### 6.2 Ghosting과 Gap의 관계

```
Gap 큼 (>10) → 과적합 → Train에서 학습한 패턴이 Val에 전이 안됨
             → 뷰 간 일관성 부족
             → Ghosting artifact 발생
```

## 7. 결론 및 권장사항

### 7.1 핵심 발견

1. **D3_normalized의 음수 Gap은 Coverage + PP=256의 조합 효과**
2. **mask_mode=none (E0)이 gt (E1/E2)보다 일반화 우수**
3. **3 view는 정보 부족으로 과적합 심화**
4. **fx 정규화 없으면 Gap 극대화 (M3: +13.4)**

### 7.2 최적 설정 권장

| 항목 | 권장값 | 근거 |
|------|--------|------|
| Coverage | **80%+** | D3 성공 |
| fx | **549** | H2 검증됨 |
| PP | **256 고정** | D3 성공, H8 |
| mask_mode | **none** | H7 |
| Views | **4v 이상** | 3v는 과적합 |

### 7.3 우선순위 실험

| 순위 | 실험 | 목적 |
|------|------|------|
| **1** | M3_persample + E0_paper | D3 재현 (PP=256, Coverage 80%) |
| 2 | M3_norm + E0_paper | PP 가변 영향 확인 |
| 3 | D3_normalized split 분석 | 음수 Gap 원인 검증 |
