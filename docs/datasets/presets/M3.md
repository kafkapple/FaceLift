## 1. 개요

M3는 **fx=739 (미정규화)** 상태의 데이터셋으로, H2 가설 (fx 정규화 효과) 검증에 사용됩니다.

| 항목 | 값 |
|------|-----|
| **Alias** | D10.3 |
| **Transform** | Homography |
| **Zoom Scope** | Global |
| **fx** | **739** (미정규화) ⚠️ |
| **PP (cx, cy)** | 가변 |
| **Coverage** | ~78.5% |
| **Val PSNR** | ~17 |

---

## 2. M3는 버그가 아님

⚠️ **중요**: M3는 버그가 아니라 **의도적 설계**입니다.

| 오해 | 실제 |
|------|------|
| M3의 fx=739는 버그? | ❌ 아님, H2 검증용 |
| M3 사용하면 안됨? | 일반 사용 비권장, 검증용 OK |
| M3_1/M3_2가 수정 버전? | M3와 다른 목적 |

### 목적

```
M3 (fx=739) vs M3_norm (fx=549) 비교
→ H2 검증: "fx 정규화가 PSNR에 미치는 영향"
```

## 3. 프리셋 설정

```python
"D10.3": {
    "paradigm": "precision_homography",
    "transform": "homography",
    "scale_mode": "individual",
    "pp_method": "shift_to_256",
    "skew_correction": True,
    "adaptive_zoom": True,
    "zoom_method": "coverage_based",
    "zoom_scope": "global",
    "zoom_center_mode": "object",     # Object-centered (PP 가변)
    "target_fg_coverage": 0.05,
    "zoom_range": [1.0, 2.5],
    "output_size": 512,
    "normalize_after_zoom": False,    # fx 미정규화
}
```

### 핵심 차이 (vs M3_1/M3_2)

| 설정 | M3 | M3_1/M3_2 |
|------|-----|-----------|
| `zoom_center_mode` | object | **image** |
| `normalize_after_zoom` | False | **True** |
| fx 결과 | 739 | **549** |
| PP 결과 | 가변 | **256** |

---

## 4. H2 가설 검증

### 가설

**H2**: fx=549 정규화가 pretrained 모델 호환성에 필수

### 검증 실험

| 데이터셋 | fx | PP | PSNR | 해석 |
|----------|-----|-----|------|------|
| **M3** | **739** | 가변 | ~17 | fx 미정규화 |
| M3_norm | 549 | 가변 | 17.09 | fx 정규화 |

### 예상 결과

```
M3 (fx=739) ≈ M3_norm (fx=549)
→ fx 정규화 자체는 PSNR에 큰 영향 없음
→ PP 정합이 더 중요 (H3)
```
