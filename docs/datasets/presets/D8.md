## 1. 개요

D8은 **Homography 변환 + Skew Correction** 방식의 정밀 데이터셋입니다.

| 항목 | 값 |
|------|-----|
| **Alias** | M2 |
| **Transform** | Homography |
| **Skew Correction** | ✅ Yes |
| **PP Method** | shift_to_256 |
| **fx** | 549 |
| **PP (cx, cy)** | 256, 256 |
| **Coverage** | ~50.5% |
| **Val PSNR** | 20.21 |

---

## 2. 프리셋 설정

```python
"D8": {
    "paradigm": "precision_homography",
    "transform": "homography",
    "scale_mode": "individual",
    "pp_method": "shift_to_256",
    "skew_correction": True,          # Affine과의 핵심 차이
    "adaptive_zoom": False,
    "target_fx": 548.9937744140625,
    "output_size": 512,
}
```

### 핵심 특징

| 특징 | 설명 |
|------|------|
| **Homography** | Affine + 원근 왜곡 보정 |
| **Skew Correction** | 카메라 기울기 보정 |
| **PP Shift** | Principal Point를 256으로 이동 |

### Affine vs Homography

| 변환 | 자유도 | 보정 범위 |
|------|--------|-----------|
| Affine | 6 | 회전, 스케일, 이동, 전단 |
| **Homography** | 8 | + 원근 변환 |
