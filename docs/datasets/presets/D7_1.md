## 1. 개요

D7_1은 **Affine 변환 + Individual Scale** 방식의 기준선 데이터셋입니다.

| 항목 | 값 |
|------|-----|
| **Alias** | M1 |
| **Transform** | Affine |
| **Scale Mode** | Individual (scale_x, scale_y 별도) |
| **PP Method** | shift_to_256 |
| **fx** | 549 |
| **PP (cx, cy)** | 256, 256 |
| **Coverage** | ~50.5% |
| **Val PSNR** | 20.93 |

---

## 2. 프리셋 설정

```python
"D7.1": {
    "paradigm": "pp_centered_shift",
    "transform": "affine",
    "scale_mode": "individual",      # scale_x, scale_y 별도 계산
    "pp_method": "shift_to_256",
    "skew_correction": False,
    "adaptive_zoom": False,
    "target_fx": 548.9937744140625,
    "output_size": 512,
}
```

### 핵심 특징

| 특징 | 설명 |
|------|------|
| **Individual Scale** | X, Y 축 스케일을 별도로 계산하여 왜곡 최소화 |
| **PP Shift** | Principal Point를 256으로 이동 (pretrained 호환) |
| **No Zoom** | Adaptive zoom 없음, Coverage ~50% |
