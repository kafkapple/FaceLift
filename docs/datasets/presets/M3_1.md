# M3_1 - Global Zoom + MVG-Correct

> **Navigation**: [← Dataset Hub](../00_INDEX.md) | [M3 Series](../M3_SERIES_SPEC.md)

> **Status**: ✅ Active (MVG-correct)

## 1. 개요

M3_1은 **Global Zoom + Center-Aligned Crop**으로 MVG 정합성을 보장하는 데이터셋입니다.

| 항목 | 값 |
|------|-----|
| **Transform** | Homography |
| **Skew Correction** | ✅ Yes |
| **Zoom Scope** | **Global** (전체 동일) |
| **Zoom Center** | **Image** (center-aligned) |
| **fx** | 549 |
| **PP (cx, cy)** | **256, 256** (MVG-correct) |
| **Coverage** | ~78% |
| **Ray Error** | **0°** |

---

## 2. 프리셋 설정

```python
"M3_1": {
    "paradigm": "precision_homography",
    "transform": "homography",
    "scale_mode": "individual",
    "pp_method": "shift_to_256",
    "skew_correction": True,
    "adaptive_zoom": True,
    "zoom_method": "coverage_based",
    "zoom_scope": "global",           # 전체 동일 zoom
    "zoom_center_mode": "image",      # ★ MVG-correct 핵심
    "target_fg_coverage": 0.05,
    "zoom_range": [1.0, 2.5],
    "target_fx": 548.9937744140625,
    "output_size": 512,
    "normalize_after_zoom": True,
}
```

### 핵심 특징

| 특징 | 설명 |
|------|------|
| **Global Zoom** | 전체 데이터셋에서 동일 zoom 계수 (1.347) |
| **Center-Aligned** | 이미지 중심 기준 crop → PP=256 자동 보장 |
| **MVG-Correct** | Ray Error 0° |

## 3. Global vs Per-sample Zoom

| 방식 | M3_1 | M3_2 |
|------|------|------|
| **Zoom 범위** | 1.347 고정 | 1.0~2.5 가변 |
| **fx 일관성** | 완전 동일 | 재정규화 후 동일 |
| **복잡도** | 낮음 | 높음 |
| **개별 최적화** | ❌ | ✅ |

### 언제 M3_1 사용?
