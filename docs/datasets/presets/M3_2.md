## 1. 개요

M3_2는 **Per-Sample Zoom + Center-Aligned Crop**으로 각 샘플별 최적 Coverage를 달성하면서 MVG 정합성을 보장하는 **권장 데이터셋**입니다.

| 항목 | 값 |
|------|-----|
| **Transform** | Homography |
| **Skew Correction** | ✅ Yes |
| **Zoom Scope** | **Per-sample** (샘플별 최적) |
| **Zoom Center** | **Image** (center-aligned) |
| **fx** | 549 (재정규화) |
| **PP (cx, cy)** | **256, 256** (MVG-correct) |
| **Coverage** | ~6% (샘플별 최적) |
| **Ray Error** | **0°** |

---

## 2. 왜 M3_2가 권장인가?

```python
    "target_fx": 548.9937744140625,
    "output_size": 512,
    "normalize_after_zoom": True,
}
```

### 핵심 특징

| 특징 | 설명 |
|------|------|
| **Per-Sample Zoom** | 각 샘플의 전경 크기에 맞춰 최적 zoom |
| **Center-Aligned** | 이미지 중심 기준 crop → PP=256 자동 보장 |
| **fx 재정규화** | zoom 후 fx를 549로 재정규화 |

---

## 4. Per-Sample Zoom 동작

```python
# 각 샘플별로 coverage 계산 후 zoom 결정
for sample in samples:
    coverage = sample.mask.sum() / (512*512)
    zoom = sqrt(target_coverage / coverage)  # 샘플마다 다름

    # Center-aligned crop (PP=256 보장)
    crop_x = (512 - crop_size) // 2
    crop_y = (512 - crop_size) // 2

    # fx 재정규화
    fx = fx * zoom
    fx = normalize_to_549(fx)
```

## 10. Troubleshooting

### Q: PP가 256이 아닌 경우

**원인**: `normalize_after_zoom` 버그 (2026-01-25 수정됨)

**해결**:
1. 최신 코드 pull
2. M3_2 데이터셋 삭제 후 재전처리

### Q: Coverage가 예상보다 낮은 경우

**확인**: `zoom_range` 설정 확인 (기본 [1.0, 2.5])
