## 5. Ray Error 공식

```
θ_error = arctan(Δpp / fx)

여기서:
- Δpp = sqrt((cx - 256)² + (cy - 256)²)
- fx = 549 (정규화 후)

예시:
- M3_norm: Δpp = 78px → θ = arctan(78/549) = 8.1°
- M3_persample: Δpp = 52px → θ = arctan(52/549) = 5.4°
- M3_1/M3_2: Δpp = 0 → θ = 0° ✅
```
