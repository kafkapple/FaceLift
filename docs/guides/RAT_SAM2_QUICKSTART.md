## B. M3_M4 Social Pair — Annotate + Propagate

### Step 1: Test Keypoint-Guided First

Before manual annotation, test if kp_sam2_segment.py works:

```bash
# Quick test: 20 frames × 6cam
CUDA_VISIBLE_DEVICES=6 python segmentation/kp_sam2_segment.py \
    --start 0 --end 1000 --step 50 \
    --cameras 1,2,3,4,5,6 \
    --output data/2022_09_22_M3_M4/kp_masks_test
```

Check output quality visually. If good (both rats cleanly separated) → skip manual annotation, run full:

```bash
CUDA_VISIBLE_DEVICES=6 python segmentation/kp_sam2_segment.py \
    --start 0 --end 89100 --step 30 \
    --cameras 1,2,3,4,5,6 \
    --output data/2022_09_22_M3_M4/kp_masks_full
```

### Step 2: Manual Annotation (if kp-guided insufficient)

#### Option A: Gradio Annotator (single camera, interactive SAM2)

⚠️ **Path note:** `sam2_annotator.py` saves to `data/sam_annotations/`, not to `masks/Camera{i}/annotations/`. After annotating, copy files to the correct location for propagation.

```bash
# On gpu03:
CUDA_VISIBLE_DEVICES=6 python segmentation/sam2_annotator.py --share --port 7860

# On local Mac (SSH tunnel):
ssh -L 7860:localhost:7860 gpu03
# Open in browser: http://localhost:7860
```

After annotating, move masks to propagation-compatible path:
```bash
cp data/sam_annotations/ann_frame_*.npz \
   data/2022_09_22_M3_M4/masks/Camera1/annotations/
```

#### Option B: Multi-Camera Viewer (6cam, brush + optional SAM2)

```bash
# On gpu03:
CUDA_VISIBLE_DEVICES=6 python viewers/mask_annotator.py \
    --session data/2022_09_22_M3_M4 \
    --port 8770

# On local Mac (SSH tunnel):
ssh -L 8770:localhost:8770 gpu03
# Open: http://localhost:8770
```

**This saves directly to `masks/Camera{i}/annotations/`** — propagation-compatible.

#### Annotation Guidelines

| Aspect | Recommendation |
|--------|---------------|
| **Frames per camera** | 10-15 keyframes, evenly spaced |
| **Suggested frames** | 0, 5000, 10000, 20000, 30000, 45000, 60000, 75000, 85000 |
| **Behavior transitions** | Add 3-5 frames at grooming, rearing, locomotion changes |
| **Per-frame time** | ~2 min (click positive on each rat, refine edges) |
| **Total time** | ~25 min/camera × 6cam ≈ 2.5 hours |
| **Two rats** | Mark `animal_0` (Rat1, blue) and `animal_1` (Rat2, orange) |

### Step 3: Video Propagation

```bash
# Camera 1 (already has 11 annotations — can propagate now)
CUDA_VISIBLE_DEVICES=6 python segmentation/sam2_propagate.py \
    --session data/2022_09_22_M3_M4 \
    --cameras 1 \
    --mode sparse --step 30 \
    --model base_plus \
    --output data/2022_09_22_M3_M4/masks/Camera1/propagated/rat2_full

# All cameras (after annotation complete):
for cam in 1 2 3 4 5 6; do
    echo "=== Camera $cam ==="
    CUDA_VISIBLE_DEVICES=6 python segmentation/sam2_propagate.py \
        --session data/2022_09_22_M3_M4 \
        --cameras $cam \
        --mode sparse --step 30 \
        --model base_plus \
        --output data/2022_09_22_M3_M4/masks/Camera${cam}/propagated/full
done
```

**Propagation modes:**
- `sparse --step 30`: Every 30th frame + all keyframes (~3000 masks/cam)
- `keyframe-segments --context 2000`: ±2000 frames around each keyframe
- `full --step 5`: Dense (slow, ~18000 masks/cam)

### Step 4: Quality Review
