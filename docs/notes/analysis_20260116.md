## 5. Turntable 품질 문제 분석

### 5.1 Why: 왜 turntable 결과가 안좋은가?

**원인**: Turntable은 **novel view synthesis** 결과
- 학습 데이터: 6개 고정 카메라 뷰
- Turntable: elevation=0°(또는 20°)에서 360° 회전 렌더링
- 학습 시 본 적 없는 각도에서의 렌더링

### 5.2 Turntable 카메라 설정


### 5.3 supervision vs turntable 관계

| 항목 | supervision | turntable |
|-----|-------------|-----------|
| 카메라 포즈 | 학습 데이터와 동일 | 완전히 새로운 궤적 |
| 뷰 종류 | Input views (seen) | Novel views (unseen) |
| 기대 품질 | 높음 (재구성) | 낮음 (일반화) |
| 용도 | 학습 품질 확인 | Novel view 성능 평가 |

**이론적으로**: supervision의 특정 방향 뷰를 turntable에서 찾을 수 있지만, turntable은 연속적인 회전 궤적이므로 정확히 일치하지 않음

## 6. 문제 원인 분석

### 6.1 Mask 확장 문제의 근본 원인

1. **RGB Threshold 기반 mask (0.1)가 너무 낮음**
   - 렌더링된 배경이 완벽한 흰색(1.0)이 아닌 경우
   - `color_distance > 0.1`이 배경 영역까지 포함

2. **Gaussian 확산 (Ghost Gaussians)**
   - 학습이 진행되며 Gaussian들이 object 외부로 확산
   - rendered_alpha가 실제 object 영역을 넘어섬

3. **Alpha threshold 0.5 문제**
   - Ghost Gaussian의 alpha가 0.5 이상이면 foreground로 분류
   - 경계가 불명확해짐

### 6.2 PSNR 급락 원인 (v15)

가설:
1. **Overfitting to training views**
   - Input views에 과적합
   - Novel view 일반화 능력 상실

2. **Background loss의 역효과**
   - background_loss_weight=1.0이 특정 시점 이후 불안정화
   - mask 영역이 확장되면서 loss 계산 영역 변화

3. **Learning rate / gradient 문제**
   - lr=1e-6이 너무 낮아 local minimum에 갇힘
